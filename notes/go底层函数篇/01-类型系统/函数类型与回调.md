# 函数类型与回调（StreamHooks 里的 `func(...)` 字段）

> 来源：2026-11-19 学习 Step 3 时提问。当时选中 model.go:54-59。
> 分类：01-类型系统 ｜ 关联：[messages-api-fields.md](../../messages-api-fields.md)（StreamHooks 是 L2→L0 的渲染契约）

## 当时选中的代码

```go
// StreamHooks L2→调用方 的渲染契约：模型层只报告发生了什么，怎么画是上层的事
type StreamHooks struct {
	OnBlockStart func(blockType string)       // thinking | text |（S4 起 tool_use）
	OnDelta      func(deltaType, text string) // thinking_delta | text_delta
	OnBlockStop  func(blockType string)
}
```

## 问题

这里的 `func()` 函数类型看不懂，解释一下概念。

## 解答

核心一句话：**在 Go 里，函数本身可以当作值——可以存进变量、塞进结构体字段、当作参数传来传去。**

### 1. 逐词拆解

```go
OnBlockStart func(blockType string)
```

把它当成普通的字段声明来读，和 `Name string` 一模一样：

| 部分 | 含义 |
|------|------|
| `OnBlockStart` | 字段名 |
| `func(blockType string)` | **字段的类型**：一个「接收一个 `string` 参数、不返回任何值」的函数 |
| (整体) | 这个字段里存的是一个函数，不是字符串、不是数字 |

所以 `func(blockType string)` 就是一个**类型**（函数类型）——它描述的不是数据长什么样，而是**这个函数长什么样**：参数是什么、返回值是什么。

同理：`OnDelta func(deltaType, text string)` = 类型为「接收两个 string、无返回值的函数」。

### 2. 为什么要把函数存进结构体？

因为**模型层不想管 UI 怎么画**，它只想说「某个时刻发生了一件事」，把「怎么处理这件事」交给调用方决定——注释里写的「模型层只报告发生了什么，怎么画是上层的事」。这就是**回调（Hook）**模式：

- **下层（model.go）** 在合适的时间点调用这些字段里存着的函数，报告事件；
- **上层（main.go / 调用方）** 往这些字段里塞进自己的函数，决定收到事件后干什么。

model.go 里怎么**调用**（model.go:130-131）：

```go
if hooks.OnBlockStart != nil {      // 上层有没有塞函数进来?
    hooks.OnBlockStart(blockType)   // 有就调用它，把 blockType 传过去
}
```

### 3. 上层怎么用（main.go:22-42 的 consoleHooks）

调用方构造 `StreamHooks`，把**匿名函数**塞进字段：

```go
hooks := StreamHooks{
    OnBlockStart: func(blockType string) {
        if blockType == "thinking" { fmt.Print(ansiDim + "〔思考〕") }
    },
    OnDelta: func(deltaType, text string) {
        if deltaType == "thinking_delta" { fmt.Print(ansiDim + text) } else { fmt.Print(text) }
    },
    // ...
}
chatStream(ctx, messages, hooks)
```

匿名函数的签名必须和字段类型一致（接收一个 string、无返回值），否则编译报错。

### 4. 类比

把 `StreamHooks` 想象成一个「电话本」：里面存的不是电话号码，而是三个**函数**。模型层在特定时刻（开始一个块 / 来了文字 / 结束一个块）就「打一个电话」——调用对应的函数，把相关信息当作参数递过去。接到电话后干什么，由留下号码的人（调用方）说了算。

### 5. 为什么要判 `!= nil`？

三个字段可以**不填**。调用方不关心某事件就留空（`nil`），模型层调用前先检查，避免对空函数调用导致 panic。

## 一句话总结

> `func(xxx)` 是一种类型（函数类型），描述「一个函数该长什么样」；结构体里存函数，是为了让**下层报告事件、上层决定行为**，实现解耦——Go 里非常常见的回调写法。
